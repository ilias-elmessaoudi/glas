# Glas

Spotify, in Glas. Eine Web-App im Liquid-Glass-Look, die die Spotify-App über die offizielle Web-API steuert (Spotify Premium nötig).

- Vorschau mit Beispieldaten: `?demo` an die Adresse hängen.
- Beim ersten Start die Client-ID einer eigenen Spotify-Entwickler-App eingeben.
- Auf dem iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
